p4rakernel is the paraconsistent computation layer of the **Imscribing Grammar**: a Lean 4 kernel fork, the p4ramill formalization library, and a Python runtime mirror. It studies computation in the Belnap FOUR ambient $N, T, F, B$, where `B` is the held/both value. The Grammar supplies twelve primitive coordinates, the Crystal supplies their finite address space, and the kernel fork blocks direct explosion from `False` when paraconsistent mode is enabled.

## Build

```bash
cd p4rakernel
mkdir -p build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make stage0 -j$(nproc)
make stage1 -j$(nproc)

cd ../p4ramill
export PATH="$PWD/../build/stage1/bin:$PATH"
lake build
```

`lake build` is the primary health check. Open obligations stay explicit as axioms or `sorry`; a green build means the interfaces typecheck, not that every Millennium conjecture is resolved.

## Layout and pipeline

```text
p4rakernel/
├── src/                       Lean kernel fork
├── p4ramill/Imscribing/       Primitives, Paraconsistent, Millennium, IUTT
├── p4ramill_py/               Python runtime mirror
├── kernel_patches/            patch reference files
└── doc/                       extended documentation
```

Bridges run `native datum → calibrated packet → ambient state → Witness → Θ transport → Closure`, with $\mu\circ\delta = \mathrm{id}$ as the closure test. ABC, BSD, RH, Hodge, Navier–Stokes, Yang–Mills, Goldbach, and OPN have bridge modules exposing finite or conditional readings without silently promoting an open global statement into a conventional theorem.

## Kernel mode

```lean
import Init.Paraconsistent
enable_paraconsistent
#is_paraconsistent       -- paraconsistent = true
disable_paraconsistent
```

With the toggle enabled, new direct recursor use such as `h.rec` for `h : False` is rejected. See [`doc/README_FULL.md`](doc/README_FULL.md) for behavior and implementation files.

## Themes

- **Belnap FOUR and SIXTEEN₃:** truth, falsity, information, and held states.
- **Crystal:** finite product address space generated by the Grammar.
- **IUTT:** filtered packets, observables, transport, endpoint closure.
- **Witness/Closure:** value-level evidence retaining the constructor tag; `Verdict.held` records independent readings as `B`.
- **Machine backing:** SIC-POVM, quantum, Vox, and runtime checks alongside Lean.
