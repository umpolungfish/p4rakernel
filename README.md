![Lean 4](https://img.shields.io/badge/language-Lean%204-2E7D32?style=for-the-badge)

p4rakernel is the paraconsistent computation layer of the **Imscribing Grammar**.
It contains a Lean 4 kernel fork, the p4ramill formalization library, and a Python
runtime mirror. The project studies computation in a Belnap FOUR ambient:

\[
N,\ T,\ F,\ B,
\]

where `B` is the held/both value. The Grammar supplies twelve primitive
coordinates, the Crystal supplies their finite address space, and the kernel
fork prevents direct explosion from an empty proposition when paraconsistent
mode is enabled.

## Build

```bash
cd p4rakernel
mkdir -p build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make stage0 -j$(nproc)
make stage1 -j$(nproc)

cd ../p4ramill
export PATH="$PWD/../build/stage1/bin:$PATH"
lake build
```

`lake build` is the primary health check. Open mathematical obligations remain
explicit as axioms or `sorry`; a green build means the formal interfaces type
check, not that every Millennium conjecture has been resolved.

```text
└── doc/                         extended documentation
```

The current bridges follow:

```text
native datum → calibrated packet → ambient state
             → Witness → Θ transport → Closure
```

ABC, BSD, RH, Hodge, Navier–Stokes, Yang–Mills, Goldbach, and OPN now have
bridge modules. They expose finite or conditional readings without silently
turning an open global statement into a conventional theorem.

## Kernel mode

```lean
import Init.Paraconsistent
enable_paraconsistent
#is_paraconsistent       -- paraconsistent = true
disable_paraconsistent
```

With the toggle enabled, new direct recursor use such as `h.rec` for
`h : False` is rejected. The detailed behavior and implementation files are in
[`doc/README_FULL.md`](doc/README_FULL.md).

## Formalization themes

- **Belnap FOUR and SIXTEEN₃:** truth, falsity, information, and held states.
- **Crystal:** the finite product address space generated by the Grammar.
- **IUTT:** filtered packets, observables, transport, and endpoint closure.
- **Witness/Closure:** value-level evidence retaining the constructor tag;
  `Verdict.held` records independent readings as `B`.
- **Machine backing:** SIC-POVM, quantum, Vox, and runtime checks alongside Lean.
