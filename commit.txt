All four Grammar axioms demoted: every one of them proved False

I checked A, B and C after finding it in D, and all three had the same defect.
Each said "X requires Y" and was written with BOTH values universally quantified,
so the antecedent never touched the value named in the consequent and the axiom
asserted that consequent of everything:

  A  (h) (k) : h = wool → (k = egg ∨ k = on)      k free
  B  (p) (h) : p ≥ ah   → h ≥ sure                h free
  C  (d) (t) : t = are  → d = if'                 d free
  D  (d)(t)(p)(pol) : … → pol = or'               pol free

Instantiate the free value at anything the consequent denies and noConfusion
does the rest. I proved False from each before changing any of them and printed
the dependencies: axiomA_False rests on nothing but its own axiom.

A, B and C had no call sites at all — declared, never used, unsound the whole
time. Only D was load-bearing, and it made its consequences vacuous: it proved
bsdResolved.pol = or' whatever that polarity actually was, and
Hodge_KernelCrossing carried the inconsistency as a stated lemma,
hodge_polarity_forced_pm_sym (pol : Polarity) : pol = or'.

All four are now decidable predicates on an Imscription, which reads the value
off the structure instead of quantifying over it. That is the repair and it is
also the demotion: every field of a concrete imscription is a constructor, so
each instance is settled by decide and needs no axiom. The three former D
consequences now depend on propext alone or on nothing.

Named Imscriptive, not Holographic. Holographic is the static subset — a
boundary encoding a bulk it does not write — and these constraints are the
general condition. I corrected if''s own doc comment in Core.lean too, which
called it holographic outright and is where the confusion started.

GrammarAxioms_Demotion.lean is the guard. Each predicate is checked twice: it
HOLDS for bsdResolved, and it FAILS for a witness built to break it with the
signature left intact. A predicate that cannot fail is not a claim, and that
falsifiability is exactly what the axiom form could not express.
