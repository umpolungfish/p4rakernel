Sorry audit (uniform, no MPP privileged): fix false/vacuous statements, prove one

Treated every in-build sorry on its own merits rather than granting MPP files a
"boundary" free pass. Four changes; whole p4ramill library stays green (lake
build = 0 jobs).

WorldReligions.lean
  Oinf_requires_pm_sym: was `sorry`; now PROVEN. `ouroborTier s = Oinf` only fires
  the first branch, whose guard requires `s.P = pm_sym`; `split_ifs at h` discharges
  every other branch by constructor mismatch, leaving `exact h1.1`.

OPN_Witness.lean
  opn_nonexistence_proved: was `¬ ∃ (N : ℕ), True` — a FALSE statement (∃ N, True
  holds at N=0), so its sorry was undischargeable in principle. Restated to the
  module's honest `OPNConjecture` (∀ N, ¬ IsOddPerfect N). The sorry now marks the
  genuine open problem.

BSD_Resolution.lean
  bsd_rank_equals_ord_vanishing: was `∀ (E_rank L_ord : ℕ), E_rank = L_ord` —
  asserts all naturals are equal, FALSE. Restated to `Millennium.BSD.BSDRankConjecture`
  (ellipticRank W = analyticRank W for every E/ℚ).

NS.lean — de-vacuufy Navier-Stokes global regularity
  NSGlobalRegularity was `∃ u p, True ∧ ∃ C, 0 < C ∧ ∀ t x, ‖u t x‖ ≤ C`: the PDE
  was stubbed `True` and nothing bound u to u₀, so u ≡ 0, C = 1 satisfied it — a
  hollow shell, not the Clay problem. Added two abstract predicates in the file's
  own Layer-1 axiom idiom:
    axiom SolvesNS (u₀) (u) (p) : Prop        -- the NS system + div u = 0 + u(0)=u₀
    axiom IsGloballySmooth (u) : Prop         -- C^∞ with all Sobolev norms finite
  and require both:
    NSGlobalRegularity u₀ := exists u p, SolvesNS u₀ u p and IsGloballySmooth u and
                                    exists C, 0 < C and forall t x, ‖u t x‖ ≤ C
  SolvesNS binds the witness to u₀ (an opaque Prop with no constructor), so the
  statement is no longer trivially provable. sorry_iff_ns / ns_threshold /
  ns_certificate_is_minimal are Iff.rfl / passthrough and are unaffected; no
  non-sorry construction of NSGlobalRegularity existed, so nothing real breaks.
  Declaring opaque Prop-valued functions is conservative, no unsoundness.
