Difference sets: a thick set has density one, not zero

The counterexample the file leaned on was backwards. It refuted the converse —
syndetic D(A) implies d*(A)>0 — by saying "thick sets have d*(A)=0 but syndetic
D(A)". A thick set contains arbitrarily long intervals, so a window of every
length is completely full and its upper Banach density is 1.
thick_not_banach_zero proves it: density zero would put every window at some
scale below the full fraction, and thick_window_full produces a full window at
that very scale. A counterexample to the converse has to be a density-zero set
whose difference set still has bounded gaps, and thickness supplies the opposite
of that.

Both halves of the dichotomy are now defined and related. Syndetic is bounded
gaps, thick is arbitrarily long runs, and they are dual:
thick_iff_compl_not_syndetic. A syndetic set meets EVERY window of its gap
length, so its lower density is already positive — strictly more than the thick
set was being asked to supply.

The lacunary side is a bound rather than an asymptotic. If 2^a − 2^b = d with
d > 0 then 2^b ≤ d, because the cofactor 2^(a−b) − 1 is at least one, and hence
2^a ≤ 2d. Both exponents are pinned by d, so each non-zero difference is
realised finitely often and D({2ⁿ}) = {0}.
