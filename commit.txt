The second split, as the criterion rather than a family

The fixed-point rule is what found this. The rung test is a congruence — a
conservative action — and the rule says conservative operators populate only
{one-shot, no-closure}, never a basin. So when the instrument could not close
n = 2521, that was not "nearly": a conservative operator either lands or does
not, and the only way to be wrong about it is to be reading the wrong stabiliser
set. I was. The set is the divisors of M², not of M.

r/M = 1/b + 1/c holds exactly when some u with u·v = M² satisfies r ∣ M+u and
r ∣ M+v, because (M+u)(M+v) = M² + M(u+v) + uv = M(2M+u+v). The earlier lemma is
the case u = d, v = M²/d for a divisor d ≡ −1 (mod r) of M itself; this ranges
over strictly more divisors. second_split_general carries it, proved by one
cancellation of r rather than by a search.

With the criterion right, 2521 closes on rung 23:
4/2521 = 1/636 + 1/69748 + 1/131876031, and that is a theorem in the file.

The instrument re-swept: 5 ≤ n ≤ 20000, 3333 values in the class, every one
closed, and the highest rung needed is 23. So the conjecture now rests on one
question — whether the rung height is BOUNDED. A fixed R that works for every n
gives Erdős–Straus. That is a question about the rungs, and a sweep does not
answer it.
