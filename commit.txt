GeneToProtein: three theorems that stated True now state something

The file backing the gene-to-protein chain carried its content in docstrings and
proved nothing. total_path_distance_approx, closure_theorem and
consciousness_invariant each read `: True := by trivial`, with the actual claims
written in comments and marked verified by a Python run.

They are statements now, decided over the morphism list itself: the path has six
morphisms, each begins where the last ended so no stage is skipped or revisited,
every morphism moves the type so no stage restates the one before it, folding and
assembly each move at least as many primitives as splicing, and the path starts at
the gene and ends at the assembled complex. The path length is a definition over the
distances rather than a number asserted in prose.

The header comment carried the pre-revision assignment a sixth time, with histidine
on Granularity, asparagine on Coupling and glutamine on Criticality, directly above
code that calls the canonical map. Corrected, and written in the marks: asparagine
divides, glutamine rejoins, histidine is criticality.
