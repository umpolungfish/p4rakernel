Eleven Erdős proof modules taken off sorry, and three false claims found under it

Every sorry in the Erdős proof modules is gone. Where the statement is a cited
theorem it is now a Prop and the results that used it take it as a hypothesis,
so nothing in these files rests on sorryAx and the cited results are visible as
citations rather than as proofs. Where the statement was wrong, that is written
down with the refutation beside it.

Three were wrong, not merely unproved.

DistinctDistances defined g(n) as an infimum: sInf { m | ∀ P, |P| = n →
count P ≥ m }. That set is downward closed and contains 0, so g_distinct was
identically zero, and guth_katz_computable — asserting g(n) ≥ (1/10)·n/log n for
all n ≥ 2 — was asserting 0 ≥ a positive number. Both halves are proved:
g_distinct_eq_zero and guth_katz_computable_is_false. The quantity wanted is the
supremum of the same set.

LCMSieve asserted that lcm(1,…,n) ≤ n·log n for most n, as a density tending to
zero. It tends to one. The comment beneath the claim quotes the prime number
theorem as e^{n(1+o(1))} and Chebyshev as ≤ 4ⁿ, and an exponential is not
eventually below n log n. The elementary reason needs no analytic number theory:
n and n−1 are coprime and both divide lcm(1,…,n), so lcm ≥ n(n−1), while
log(n+1) < n−1 from n = 3. Every n ≥ 3 is in the excess set —
excess_of_three_le.

RamseyLimit's refined base comparison used (4n−2)/3.199. That base is below one
only at n = 1; at n = 2 it is 6/3.199 and it grows with n, so the refinement
diverged for every n ≥ 2 instead of vanishing. base_exceeds_one_from_two proves
it. The bound that works is the exponential Bondy-Erdős form (2n+1)·2^k, whose
base against Schur is 2/3.199 for every n, with the n-dependence in the constant
rather than the base — and the comparison is now proved from that, not sorried.

Four smaller corrections. FurstenbergSarkozy counted representations over
Finset.Icc 0 (sSup A + d), and sSup on ℕ returns the junk value 0 for a set with
no upper bound, which is every set the theorem is about — the window had
collapsed to Icc 0 d. HypergraphRamsey asserted R(2,n) ≥ 2ⁿ while its own
comment quoted the classical 2^{n/2}. HopfPannwitz recorded tightness as n−1
edges when the bound n is attained, by the Reuleaux polygon at odd n. And three
statements wrote a square or a difference as b − a = d on ℕ, where truncated
subtraction makes it hold for b ≤ a and carry no ordering; they are a + d = b
now.

What is proved rather than cited: ErdosFuchs gets the counting identity
∑_{n<N} r_A(n) = #pairs and the square-root density bound a basis of order 2
forces, HopfPannwitz gets its asymptotic form from the edge bound, RamseyGap
gets the unbounded gap from divergence, TrianglePartition gets sufficiency from
Kirkman, and SumFreeSets gets the elementary half of Cameron-Erdős — the odd
numbers are sum-free and there are ⌊N/2⌋ of them, which is where the exponent
comes from.
