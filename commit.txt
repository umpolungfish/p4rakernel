vox_elf_audit.sh: add the repair and decompose steps it was missing

This script already did half of what "compile Lean to ELF and audit it with
Vox" means: lake build's generated C, compiled with leanc, swept through vox
for a real control-flow census. What it never did was the other half: for a
function vox itself calls B or F, extract that function's own word, say what
each mark in it means in plain language, and run it through mOMonadOS's
insert to find single-glyph repairs. That meant every flagged function still
had to be chased by hand afterward.

VOX_AUDIT_REPAIR=1 now runs that second half automatically, module by module,
using vox word plus vox verdict to find each function's own B/F reading
(never the module aggregate, which mixes them together), a fixed twelve-mark
table for the decomposition, and a shell to mOMonadOS's insert for the
repair. Capped at VOX_AUDIT_REPAIR_MAX (default 20) across the whole run, not
per module: the first full sweep here found 13101 B-verdict functions across
604 modules, and repairing all of them one mOMonadOS boot at a time is hours,
not a session. The cap reports exactly what it skipped, both functions past
it in an opened module and whole modules never opened at all, rather than
silently doing part of the job.

Verified against the real corpus: 604 modules, 0 compile failures, a capped
repair pass that correctly decomposes and repairs real flagged functions and
reports the true remainder.
