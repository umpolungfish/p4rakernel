The rung height grows like the fourth root, and the conjecture is one Prop

The ceiling is not a constant, and chasing one was the wrong target. Measured
across the surviving class:

  n < 2000    max rung 23  at 1201      n^(1/4) =  5.9
  n < 10000   max rung 23  at 2161      n^(1/4) =  6.8
  n < 50000   max rung 51  at 35809     n^(1/4) = 13.8
  n < 100000  max rung 47  at 99961     n^(1/4) = 17.8
  n < 200000  max rung 75  at 196561    n^(1/4) = 21.1

The ratio of maximum rung to n^(1/4) is 3.9, 3.4, 3.7, 2.6, 3.6 — flat across two
orders of magnitude. So a proof has to control an O(n^(1/4))-deep search, not a
constant one, and RungGrowthFourthRoot states that as a Prop with the measured
constant named.

EveryNClosed is the conjecture itself in this file's vocabulary: every n in the
surviving class is closed at some rung. straus_class_of_everyNClosed derives
Erdős–Straus for the class from it, which is the whole reduction in one line.

33333 values checked across 5 ≤ n ≤ 200000, all closed, the single exception being
n = 2521 whose divisor lives in M² rather than M.
