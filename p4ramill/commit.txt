Extend Gödel-completeness onto the corpus Belnap and wire in its theorems

The Gödel-completeness file reinvented a minimal Belnap. Rebuild it on the corpus's
own carrier, Imscribing.Paraconsistent.Belnap, and reuse the proven machinery so
the faces connect to the rest of the kernel instead of a private copy.

Five faces, now corpus-grounded:
  - Ambient hosts it: bnot has a fixed point B (B_fixed_point_negation), fixed set
    exactly {N, B}.
  - Unique rest point: that value is forced. inc, the operator that augments a
    system with its own Gödel sentence, drives every state up the information order
    to B, whose only fixed point is B (inc_fixed_point_iff). This is the new,
    stronger face over the earlier standalone Inc.
  - Classical cannot: classical negation on {F,T} has no fixed point, and no
    classical endomap reproduces inc, whose image is B (inc_image_is_B).
  - No explosion: the glut is designated with its negation while some formula is
    not, and B ∧ ¬B = B not F (no_explosion), so ex falso fails.
  - Self-imscription: μ∘δ = id is now the kernel's real split_fuse_identity, not a
    toy marker tower.

grammar_godel_complete bundles the five. Depends on propext alone, sans sorry. Vox
re-audit of the lifted proof words: T for the two forking proofs, N for the four
direct terms, none B or F, and the sorry control still reads B.
