Audit the Gödel-completeness proof with Vox, and record the control

Add Imscribing/GodelCompletenessAudit.lean: lift each proof term of
GodelCompleteness to its IMASM structure word with #lift, so vox verdict reads
whether the proof closes.

The ELF route was a decoy and the control caught it: compiling the module to a
shared object and auditing it read T0 B2 N18 F0, but a different module
(ParaconsistentCore) compiled byte-identical with the same verdicts, because Lean
erases Prop and the binary holds only module-init glue. The binary is not the word.

The real audit is the proof-lift. vox verdict on the lifted words:
  godel_absent_from_classical  T   (fork closes)
  boolean_impossibility        T   (fork closes)
  grammar_godel_complete       N   (forkless bundling)
  godel_fixed_point_in_ambient N
  no_ex_falso                  N
  grammar_self_imscribes       N
None reads B or F. The control fixes the meaning: a holed proof, ∃ n, n = n+1 by
sorry, lifts to ⊢∈⊣ and reads B, the fork opened and never rejoined. So the
instrument does separate a closed proof from an open one, and every real theorem
here is closed or forkless, none open, none ill-typed.

Corroborated by the kernel: #print axioms grammar_godel_complete reports it depends
on no axioms at all, no sorry, no Classical, no propext.
