Strengthened vox_elf_audit.sh's repair pass. It only ever tried a
single-glyph insert on the word as compiled, the shallow check. Today's
manual work on three real B-verdict objects (DialetheicWitness.o,
CosmicHolonomy.o, OuroboricHolomorphicAutomeshedWindingSpectrum.o) went
further: combo2 across every distinct rotation of the word, weight |
banked | insert | repair each, then a second pass on whatever the first
pass repaired. Every one of those five distinct words, checked that way,
came back with no rotation producing a repair -- a real, exhaustive
negative result, not a shallow one. The script now runs combo2 too, and
keeps the output compact: one line when nothing is found (the common
case, checked automatically now rather than by hand), the full second-
pass output when something actually is, since that would be rare enough
to be worth reading in full.

Verified against the known case before trusting it for a wider run:
called repair_flagged_functions directly on DialetheicWitness.o, same
one addressable B, same "no rotation produced a repair" result the
manual combo2 run gave, automatically now.
