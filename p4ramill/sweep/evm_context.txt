Operations in full: STOP, ADD, SUB, MUL, DIV, MOD, EXP, LT, GT, SLT, SGT, EQ,

REVERT, INVALID, SELFDESTRUCT.

Execution is a single pass over a byte array with a program counter. Control
transfer takes an absolute byte offset from the stack, and an offset is a legal
destination only if the byte there is the designated destination marker. Storage
is a persistent key-value map surviving the call; stack and memory do not.
Execution is metered and exhausting the budget ends it.
